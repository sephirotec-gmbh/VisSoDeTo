# Kanban task template

## Goal

State one observable outcome.

## Context

Link relevant `.visodeto` nodes, decisions, parent cards, and repository areas. Do not paste duplicate truth.

## Scope

List work explicitly included in this card.

## Out of scope

List adjacent work that must not be added silently.

## Acceptance criteria

- [ ] Observable criterion
- [ ] Observable criterion

## Constraints

Record architecture, security, compatibility, and product constraints.

## Workspace

Coding cards use `worktree` or `--project visodeto`. Documentation-only cards may use an explicitly approved shared directory.

## Verification

List required tests, linters, builds, previews, migration checks, or security checks.

## Handoff

Include changed files, executed checks and outcomes, decisions, limitations, and the requested reviewer. Default reviewer for code-changing work: `quality-security`.
